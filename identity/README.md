# identity/

This folder holds the local OpenClaw device's Ed25519 keypair and the
operator token used to authenticate against the gateway.

## Files

| File | Purpose |
|---|---|
| `device.json` | Ed25519 keypair + 64-hex deviceId. Auto-generated by `openclaw doctor --fix` on first launch. |
| `device-auth.json` | Operator-role bearer token. Rotated by `openclaw devices rotate`. |

## How to populate

The real files are auto-generated. **Do not commit them.** If you cloned this
repo into `~/.openclaw`, just run:

```bash
openclaw doctor --fix
```

OpenClaw will create both files with fresh keys. The `.example` files in
this folder show the schema only.
