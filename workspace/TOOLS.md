# Trading tools

Volume **always 0.05**. When the signal has no zone, pass `0 0`. TP is
TP1 only (ignore TP2 / TP3).

## `mt5_buy`

```
python skills/mt5-trading-assistant/scripts/mt5_buy.py <volume> <zone_min> <zone_max> <SL> <TP>
```

## `mt5_sell`

```
python skills/mt5-trading-assistant/scripts/mt5_sell.py <volume> <zone_min> <zone_max> <SL> <TP>
```

## `mt5_close_all`

```
python skills/mt5-trading-assistant/scripts/mt5_close_all.py all
```

## `mt5_check`

```
python skills/mt5-trading-assistant/scripts/mt5_check.py
```
